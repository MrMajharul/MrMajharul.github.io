# Majharul Islam — Portfolio

Creative-futuristic personal portfolio built with React, Vite, and TypeScript.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## GitHub Pages

This is configured for a GitHub user-site repository (`MrMajharul.github.io`) with `base: '/'`.

1. Push this project to `https://github.com/MrMajharul/MrMajharul.github.io`.
2. In repository Settings → Pages, choose **GitHub Actions** as the build and deployment source.
3. Add `.github/workflows/deploy.yml` (see below) or use the included workflow.

The project is static and can be hosted on GitHub Pages.
